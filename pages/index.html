OS Fingerprinting of Bitcoin Nodes

Operating system guesses for publicly reachable Bitcoin nodes, from monthly nmap scans. One scan per month, loaded straight from the dataset on GitHub.

nmap's OS detection is a best-effort guess, not a fact. A fingerprint can describe a firewall or NAT device in front of the node, guesses below 70% accuracy are downgraded to Unknown, and individual hosts can flip class between runs. Per-class proportions are the reliable signal, not any single row.

Legacy two-port scans are excluded. timeout rows are not unreachable: nmap was killed before reporting, so those hosts were never measured, and they are left out of the reachability ratio. See the README for full methodology limitations.
